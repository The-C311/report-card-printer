# Report Card Printer

A Python program that formats and displays a student's report card.

## Project Overview

This project was completed while studying Python through the freeCodeCamp curriculum. It demonstrates how variables can store student information using different Python data types, including strings, Booleans, integers, and floating-point numbers.

## Technologies

* Python 3

## How to Run

1. Clone this repository.
2. Open the project directory.
3. Run:

```bash
python3 report_card_printer.py
```

## Skills Practiced

* Creating and assigning variables
* Working with strings and numeric values
* Using formatted strings
* Organizing output in a readable format
* Running Python programs from the command line
